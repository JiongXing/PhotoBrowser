# Proposal

## Why

代码审查复现了数据缩减后的越界缩略图回调、无动画关闭后的隐藏残留、下拉期间轮播翻页，并发现 Demo 异步使用下载临时文件的生命周期风险。现有行为测试尚未接入 CI，自定义 Cell 也无法参与下拉准入判断。

## What Changes

- 浏览器统一管理缩略图显隐与恢复，避免用失效索引恢复旧数据的视图；增加可选恢复闭包接口，支持自定义显隐在数据替换后恢复。
- 下拉期间暂停轮播，回弹结束后按当前生命周期恢复；刷新、导航和尺寸转场主动结束旧交互。
- Cell 协议增加带默认实现的下拉准入属性，内置缩放 Cell 自行管理其滚动状态。
- Demo 共用视频文件保存工具，在下载回调返回前接管文件，只清理工具拥有的临时副本。
- 补充状态与系统手势回归，并把既有验证宿主接入 CI。

## Capabilities

### New Capabilities
- `browser-lifecycle`: 缩略图恢复、下拉与轮播协调、自定义 Cell 的下拉准入。
- `demo-video-saving`: 视频临时文件所有权与保存完成后的清理。

### Modified Capabilities

无。既有 `size-transition` 行为保持不变，继续运行其回归。

## Impact

影响 Sources 中浏览器、Cell 协议与缩放 Cell、Zoom 动画器，UIKit 示例的两处视频保存入口，以及 Validation、CI 和使用文档。公开接口为增量添加并提供默认实现；保留既有显隐回调，动态数据宿主的特殊显隐可通过恢复闭包捕获原始对象。不引入第三方运行时依赖，不改业务数据模型，不做通用状态机或整库重构。
