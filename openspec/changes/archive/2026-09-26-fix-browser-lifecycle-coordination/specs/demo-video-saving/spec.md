# Spec Delta

## Purpose

保证 UIKit 示例的视频保存流程在异步下载、相册写入以及 Cell 退出或复用期间正确持有待保存文件，并区分工具生成的临时副本与调用方拥有的本地源文件，避免文件提前失效或误删。

## ADDED Requirements

### Requirement: 下载文件在异步保存期间有效
示例 MUST 在下载回调返回前取得临时视频文件的所有权，并保持文件有效直到异步相册保存结束。

#### Scenario: 下载回调结束后才读取
- **WHEN** 视频已下载且相册稍后异步读取文件
- **THEN** 文件仍存在且内容完整，UI 对象释放不导致保存流程丢失文件

### Requirement: 只清理保存流程拥有的临时文件
示例 SHALL 在保存成功或失败后清理自身创建的临时副本，MUST NOT 删除调用方提供的本地源文件。

#### Scenario: 保存成功或失败
- **WHEN** 相册写入成功或失败
- **THEN** 下载文件的自有临时副本被清理，调用方本地文件保持存在
